multiview live -- command lines
===============================
Open Terminal on each Mac (Cmd-Space, "terminal", Return). Paste, Return.

HUB MacBook  (one binary: hub + camera 1)
    cd ~/Desktop/multiview-live && ./mvhub
  A preview window opens (camera 1). The Terminal shows the HUB IP in a
  box, then [cal]/[ext] progress. Close the window to finish; the whole
  session lands in  rec/.

SECOND camera MacBook  (HUBIP = the number from that box)
    cd ~/Desktop/multiview-live && ./stream_cam HUBIP 9900 2 5
  A preview window opens; a green LIVE bar = frames flowing.

PATTERN MacBook
    open ~/Desktop/multiview-live/pattern.html
  Click the page once (fullscreen, calibration mode).

Give the pattern motion where all cameras can see it (turntable / tilt).
Everything collects in rec/: frames, records.txt, camlog_<id>.txt,
hub.log, summary.txt. Pitch 0.1133 is fine (only scales distances).

If macOS ever says a binary "can't be verified" (files copied via
AirDrop carry a flag), clear it once on that Mac:
    xattr -dr com.apple.quarantine ~/Desktop/multiview-live
