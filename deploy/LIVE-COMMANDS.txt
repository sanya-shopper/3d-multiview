multiview live -- command lines (paste into Terminal)
=====================================================
Open Terminal on each Mac: Cmd-Space, type "terminal", Return.

HUB MacBook  (ONE command: runs the hub AND camera 1)
-----------------------------------------------------
  cd ~/Desktop/multiview-live && xattr -dr com.apple.quarantine . && ./mvhub

  - a preview WINDOW opens showing camera 1 (aim it at the pattern)
  - the Terminal shows the HUB IP in a box, plus [cal]/[ext] progress
  - close the window (or Ctrl-C the Terminal) to finish
  Everything is collected in  ~/Desktop/multiview-live/rec/

SECOND camera MacBook  (put the hub IP where HUBIP is)
------------------------------------------------------
  cd ~/Desktop/multiview-live && xattr -dr com.apple.quarantine . && ./stream_cam HUBIP 9900 2 5

  - a preview WINDOW opens; a green "LIVE" bar = frames are flowing
  - the hub's own window turns "camera 2 CONNECTED, frames flowing"

PATTERN MacBook  (nothing to unblock)
-------------------------------------
  open ~/Desktop/multiview-live/pattern.html
  ...click the page once (fullscreen, calibration mode).

That's it. Give the pattern motion where all cameras can see it
(turntable / tilt); watch the hub Terminal fill with [cal] then [ext].

After the run, the whole session is in rec/  (decoded frames,
records.txt, camlog_<id>.txt from each camera, hub.log, summary.txt).
