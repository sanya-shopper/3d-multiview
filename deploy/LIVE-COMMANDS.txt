multiview live -- raw command lines (paste into Terminal)
=========================================================
Open Terminal on each Mac: Cmd-Space, type "terminal", Return.

HUB MacBook  (runs the hub AND camera 1)
----------------------------------------
Tab 1 (the hub -- watch this one, Ctrl-C to stop):
  cd ~/Desktop/multiview-live && xattr -dr com.apple.quarantine . && ./livehub 9900 0.1133 rec

Tab 2 (camera 1 -- Cmd-T for a new tab):
  cd ~/Desktop/multiview-live && ./stream_cam 127.0.0.1 9900 1 5

Find this Mac's IP to give the other camera:
  ipconfig getifaddr en0

SECOND camera MacBook   (replace HUBIP with the number above)
-------------------------------------------------------------
  cd ~/Desktop/multiview-live && xattr -dr com.apple.quarantine . && ./stream_cam HUBIP 9900 2 5

PATTERN MacBook
---------------
  open ~/Desktop/multiview-live/pattern.html
  ...then click the page once (fullscreen, already in calibration mode).

Args, for reference:
  livehub    <port> <pitch_mm> <record_dir>
  stream_cam <hub-ip> <port> <camid> <fps>
Port 9900 and pitch 0.1133 are fine as-is. camid must differ per camera.
