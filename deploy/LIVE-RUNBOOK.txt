multiview live test kit  (Apple Silicon)  --  see COMMANDS.txt
==============================================================
Three Macs, one command each, run from Terminal.

  HUB     :  cd ~/Desktop/multiview-live && ./mvhub
             (hub + camera 1; preview window + hub IP in the Terminal)
  CAMERA 2:  cd ~/Desktop/multiview-live && ./stream_cam HUBIP 9900 2 5
  PATTERN :  open ~/Desktop/multiview-live/pattern.html   (click once)

Give the pattern motion where all cameras can see it (turntable / tilt);
each camera needs several angles -- a flat screen can't fake that. The
hub Terminal fills with [cal] then [ext]. The full session (frames,
records.txt, camlog_<id>.txt, hub.log, summary.txt) collects in  rec/.

No ruler for distances; 0.1133 is a MacBook Air 13.6"/15" and only
scales reported distances. If a binary "can't be verified" after
AirDrop:  xattr -dr com.apple.quarantine ~/Desktop/multiview-live
